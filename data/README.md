# Data

`questions.jsonl`: 200 questions sampled from the ForecastBench datasets
(https://github.com/forecastingresearch/forecastbench-datasets), released
under CC BY-SA 4.0 by the Forecasting Research Institute. This derived file
is shared under the same license. Built by `python -m fsyc.data` (see
`scripts/reproduce.sh`); fields are trimmed, the content is unchanged.

Karger, Bastani, Yueh-Han, Jacobs, Halawi, Zhang, Tetlock. "ForecastBench: A
Dynamic Benchmark of AI Forecasting Capabilities." ICLR 2025.
